# Validation summary

All numbers below are produced by the scripts in `benchmark/`. Each result file
is regenerated by rerunning the harness; nothing is hand-edited.

## Scenario sets and their status

| Set | n | Status | Recall | Notes |
|---|---|---|---|---|

Every failure observed on a blind set was classified before repair:
**bug** (pattern coverage, sign handling, missing documented edge — fixed at
mechanism level, never per-drug) or **limitation** (unresolvable biologic,
non-receptor mechanism, below-threshold borderline — reported, not patched).

Residual first-run misses on holdout3: mirtazapine arousal sign (record lacks
the H1 activity that dominates clinical sedation), carbamazepine ADH release
(not a receptor-target effect), alteplase (protein, unresolvable), plus
identifier-level gaps on adalimumab/rituximab that still scored via built-in
profiles.

## External label falsification

`label_check.py` compares surfaced non-anchored module directions against
openFDA label text (adverse_reactions/warnings/indications). Latest:
supported 79 / directionally checkable 154; contradictions were traced to
general model defects (fixed) or label-context artifacts and documented
scope limits (warfarin necrosis, HIT — transient/immune phenomena outside
steady-state scope).

## Robustness

- `sensitivity.py`: 56/56 qualitative verdicts preserved under dose/Vd/t½
  ×0.5–×2 and worst-case Cmax ≈ ×4/÷4 perturbations.
- `stability.py`: max |x| = 2.92 (< analytic bound 3.05), 0 nonfinite,
  0 bound violations, 0 sustained oscillators under worst-case 24 h load.
- `pk_check.py`: Tmax 4/5, Cmax 1/5 within literature ranges (protein
  binding / tissue distribution unmodeled — reported as limitation).

## Deep case study

`case_study.py`: celecoxib vs ibuprofen — the same two COX anchor rows
produce opposing thrombotic directions from measured ChEMBL selectivity
(no drug→effect table). Ablations: deleting the endothelial-PGI2 arm flips
celecoxib antiplatelet (−1.02); deleting the COX-1 arm flips ibuprofen
prothrombotic (+0.17).

## LLM comparison

`llm_compare.py`: same scenarios scored for Human13 vs LLM-only vs
LLM+molecular-grounding — direction accuracy, quiet/decoy false positives,
claimed-edge support against the real graph, run-to-run reproducibility,
provenance coverage.

## Data assimilation (OSSE)

`assimilation_eval.py`: observing-system simulation experiment. Truth =
hemorrhage (120 min); a twin at baseline without the event receives noisy
observations of 8 clinically accessible states every 30 min (continuous
nudging, gain 0.15/min, noise sd 0.03). Result: observed RMSE 0.185 -> 0.100,
latent (unobserved RAAS/ADH) RMSE 0.232 -> 0.175, every latent module
improved; forecast after nudge release at t=120 gives 0.032 vs 0.095.
Caveat: compensatory-only observables invert latent inference — the
observable panel must include upstream axis states (volume, osmolality).
